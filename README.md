# BeritaCheck: Malaysian News Political Content & Sentiment Classifier

An end-to-end NLP pipeline that scrapes Malaysian news articles, engineers linguistic features, and fine-tunes **BERT** and **RoBERTa** to classify political content and sentiment, served through a **FastAPI** backend and a **Streamlit** dashboard.

## How It Works
1. **Scraping:** collects article text from news URLs across 7 Malaysian outlets (Malay Mail, The Star, FMT, The Edge, Bernama, The Rakyat Post, The Straits Times), removing ads, datelines and boilerplate
2. **Cleaning:** filters short or broken articles and duplicates, applies lemmatization, stemming and stopword removal
3. **Feature engineering:**
   - **Political Density Score:** share of words matching a Malaysian political lexicon
   - **Subjectivity Score:** via TextBlob
   - **Framing Distance Score:** TF-IDF cosine distance of each article from the average coverage of the same story
4. **Labelling (weak supervision):** political-content labels come from a density threshold (>3.5%); sentiment labels come from TextBlob polarity
5. **Modelling:**
   - **BERT** (`bert-base-uncased`): binary political-content classification
   - **RoBERTa** (`roberta-base`): sentiment classification
6. **Serving:** FastAPI REST API with SQLite storage, plus a Streamlit dashboard that analyses a news URL in real time

## Dataset
- 137 article links covering 18 news stories, each reported by several outlets (`data/news_links.csv`)
- 89 articles remained after cleaning and filtering
- Scraped article text is **not included** in this repo out of respect for publishers' copyright. Run the training pipeline to rebuild it from the links.

## Limitations
- Labels are generated by rules (keyword density and TextBlob), so the models learn to approximate these heuristics rather than human-judged bias
- The dataset is small (89 articles), so results are a proof of concept
- The sentiment data has no negative examples

**Future work:** human-annotated labels, a larger dataset, and Malay-language articles.

## Tech Stack
Python · BeautifulSoup · spaCy · NLTK · TextBlob · scikit-learn · PyTorch · Hugging Face Transformers · FastAPI · SQLAlchemy · SQLite · Streamlit · Docker

## Quick Start
```bash
pip install -r requirements.txt
python -m spacy download en_core_web_sm

# 1. Scrape data and train models (saves to ./models/)
cd training
python beritacheck_datapreprocessing_nlp.py

# 2. Start the API (http://localhost:8000/docs)
uvicorn app.main:app --reload

# 3. Launch the dashboard
streamlit run frontend.py
```

> **Docker:** build the image after training, because the `models/` folder is required and is not included in the repo.
